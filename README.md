# PHCOM 使用说明

PHCOM 是 Windows 串口调试工具，支持 AT 指令、CSV 批量测试、文件收发、UDP 远程调试和 SSH 终端。


## 快速开始

1. 运行 `PHCOM.exe`，选择串口（也可输入如 `COM12`），默认参数为 `115200 8N1`、UTF-8；其他参数在“更多设置”中调整。
2. 点击“打开串口”，在发送框输入 `AT`，按 Enter 或点击“发送”。按 Shift+Enter 可输入多行；默认自动追加 CRLF。
3. 设备意外断开会自动重连；手动关闭串口则停止重连。

## 常用功能

- **AT 指令**：左侧搜索并双击指令可直接发送；“AT配置”可切换 INI 指令表。发送框输入指令关键字会自动展开为完整指令。
    ```ini
    [COMM]
    ver = ATI
    csq = AT+CSQ
    ```

- **CSV 批量测试**：将含 `on,timeout,type,cmd` 表头的 CSV 放入 `csv\`，点击“刷新”、选择文件并“开始测试”；`type` 可用 `str`（追加 CRLF）、`str_0` 或 `hex`。可循环执行或随时停止。
    ```csv
    on,timeout,type,cmd
    1,0.5,str,ATI
    1,1.0,str,AT+CSQ
    0,0.5,hex,41 54 0D 0A
    ```

| 列 | 说明 |
| --- | --- |
| `on` | `1` 表示执行；未启用的步骤会跳过。 |
| `timeout` | 指令发送后等待的秒数，最小为 0.1 秒。 |
| `type` | `str` 为文本并追加 CRLF；`str_0` 为文本且不追加 CRLF；`hex` 为十六进制原始字节。 |
| `cmd` | 待发送的 AT 指令或十六进制数据。 |

勾选“循环”后，整套测试会按设置的毫秒间隔重复运行。运行中点击“停止测试”可终止；进度区会显示当前步骤、轮次、发送条数和跳过条数。

### 远程调试

点击“远程”后选择角色：

| 角色 | 使用方式 |
| --- | --- |
| 远程主控 | 输入被控端提供的配对码，选择本机绑定 IPv4 地址后连接。主控无需本地打开串口。 |
| 远程被控 | 必须先打开本地串口；选择绑定 IPv4 地址后，程序显示配对码，将该码交给主控端连接。 |

远程模式使用 UDP，可与 PHCOM CLI 和 aardio 版互通。连接成功后，“远程”按钮变为“断开远程”；点击即可断开。远程被控端由主控端发送数据到本地串口，并将串口接收数据同步给主控端。

请确认双方网络可达，并允许相关 UDP 通信通过防火墙。配对码属于连接凭据，不应发给无关人员。

## 中英文界面

右上角语言按钮可在中文和 English 之间切换。切换后，界面标签、按钮、对话框以及已显示的系统消息会更新为所选语言；语言选择会保存到 `config.ini`。

## 文件位置

程序从 `PHCOM.exe` 所在目录读取 `at.ini`、`port.ini`、`csv\` 和 `config.ini`；退出时将界面设置保存到 `config.ini`。运行日志保存在 `log\`。找不到串口时请检查设备、驱动并重新展开端口列表；无响应时请核对串口参数及“加CRLF”。
