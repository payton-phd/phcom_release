# PHCOM V26.0.5 使用说明

PHCOM 是一款 Windows 串口调试工具，用于发送 AT 指令、执行 CSV 批量测试、收发原始数据，以及通过 UDP 进行远程主控/被控调试。

可直接运行发布包中的 `PHCOM.exe`。程序会从 `PHCOM.exe` 所在目录读取 `at.ini`、`port.ini`、`csv\` 和 `config.ini`。退出时会自动保存当前界面配置到 `config.ini`。

## 快速开始

1. 在顶部的“端口”下拉框选择设备串口；也可以直接输入 `COM12` 等端口名。
2. 设置波特率、数据位、停止位、校验位和编码。默认参数为 `115200 8N1`、UTF-8。
3. 点击“打开串口”。状态栏显示“已打开”及 TX/RX 计数后，即可开始收发。
4. 在发送框输入 `AT`，按 Enter 或点击“发送”。接收区会显示发送、接收和系统消息。

串口意外断开后，程序会等待端口重新出现并自动重连；手工点击“关闭串口”则会停止重连。

## 界面功能

### 串口与快捷配置

顶部可以设置以下串口参数：

| 项目 | 说明 |
| --- | --- |
| 端口 | 自动枚举系统串口；下拉列表展开时会刷新。 |
| 波特率 | 支持 1200 至 3000000，默认 115200。 |
| 数据位、停止位、校验位 | 默认 8、1、None。 |
| 编码 | UTF-8、GB2312 或 ASCII，影响文本发送和接收解码。 |
| 配置 | 读取 `port.ini` 中的配置节，可一键应用端口、波特率、编码和接收过滤。 |

串口打开后，端口参数和快捷配置会锁定，关闭后恢复可编辑。批量测试在未打开串口时会尝试自动打开串口。

批量测试行中的 DTR、RTS 勾选框用于直接切换串口控制线。状态栏会同步显示 DSR 与 CTS 的当前状态。

### AT 指令树

程序默认加载 `at.ini`。在“AT配置”下拉框可切换应用目录中除 `config.ini`、`port.ini` 外的 INI 文件；双击“AT配置”标签也可选择其他位置的 INI 文件。

INI 的指令格式如下：

```ini
[COMM]
ver = ATI
csq = AT+CSQ
```

左侧搜索框会按关键字和 AT 指令内容实时过滤。指令树支持以下操作：

| 操作 | 结果 |
| --- | --- |
| 双击一条指令 | 立即发送该 AT 指令。 |
| 选中后点击“填入发送框” | 将该指令填入底部发送框，便于修改后发送。 |
| 再次单击已选中的指令 | 进入编辑；输入 `关键字 = AT指令` 并回车保存。 |
| 编辑内容清空后确认 | 删除该指令。 |
| 点击“添加指令” | 依次输入节名、关键字和 AT 指令，添加到当前 INI。 |

在发送框中输入已定义的关键字时，程序会自动替换为对应完整 AT 指令；发送成功后，指令树会定位到该关键字所在的节。

### 发送与接收

发送框支持多行输入。按 Enter 发送，按 Shift+Enter 插入换行；多行发送会统一使用 CRLF 作为行分隔。发送成功的内容会记录到历史：按 Up 查看上一条，按 Down 向较新的记录移动，回到最新位置时清空输入框。

| 选项 | 说明 |
| --- | --- |
| HEX发送 | 将输入按十六进制字节发送。 |
| 加CRLF | 文本发送末尾追加 `\r\n`，默认开启。 |
| HEX显示 | 将接收到的数据按十六进制显示。 |
| 时间戳 | 在收发记录前添加毫秒时间戳。 |
| 记录日志 | 打开串口时在 `log\` 自动创建日志文件。 |
| 循环发送 | 按指定间隔重复发送当前发送框内容，最小 50 ms。 |

接收过滤支持以 `|` 分隔的关键字或正则表达式。点击“清屏”只清除当前显示，不影响已写入的日志；点击“保存日志”可将接收区内容导出为 `.log` 或 `.txt` 文件。

接收区通常用于查看数据，但也可直接输入和发送：可见字符会作为发送内容显示，按 Enter 发送；Backspace 可删除当前输入。接收区获得焦点时，Ctrl 加字母或控制符会直接发送相应控制字符，例如 Ctrl+Z 发送 `0x1A`。Ctrl+A 和 Ctrl+C 保留为全选和复制。

### 文件接收

勾选“接收文件”后，接收到的原始数据会写入文件。双击路径提示文字可指定目标路径和文件名；不指定时，程序会在应用目录按当前时间创建 `.bin` 文件。

开始接收文件后，界面会显示接收量；取消勾选会停止写入并关闭文件。关闭串口时也会停止文件接收。

### CSV 批量测试

将 CSV 测试计划放到 `csv\` 目录，点击“刷新”并选择文件，再点击“开始测试”。每次运行会在 `log\` 创建独立日志，文件名包含 CSV 名、端口和时间。

CSV 需要包含表头，列顺序不限：

```csv
on,timeout,type,cmd
1,0.5,str,ATI
1,1.0,str,AT+CSQ
0,0.5,hex,41 54 0D 0A
```

| 列 | 说明 |
| --- | --- |
| `on` | `1` 表示执行；未启用的步骤会跳过。 |
| `timeout` | 指令发送后等待的秒数，最小为 0.1 秒。 |
| `type` | `str` 为文本并追加 CRLF；`str_0` 为文本且不追加 CRLF；`hex` 为十六进制原始字节。 |
| `cmd` | 待发送的 AT 指令或十六进制数据。 |

勾选“循环”后，整套测试会按设置的毫秒间隔重复运行。运行中点击“停止测试”可终止；进度区会显示当前步骤、轮次、发送条数和跳过条数。

### 远程调试

点击“远程”后选择角色：

| 角色 | 使用方式 |
| --- | --- |
| 远程主控 | 输入被控端提供的配对码，选择本机绑定 IPv4 地址后连接。主控无需本地打开串口。 |
| 远程被控 | 必须先打开本地串口；选择绑定 IPv4 地址后，程序显示配对码，将该码交给主控端连接。 |

远程模式使用 UDP，可与 PHCOM CLI 互通。连接成功后，“远程”按钮变为“断开远程”；点击即可断开。远程被控端由主控端发送数据到本地串口，并将串口接收数据同步给主控端。

请确认双方网络可达，并允许相关 UDP 通信通过防火墙。配对码属于连接凭据，不应发给无关人员。

## 中英文界面

右上角语言按钮可在中文和 English 之间切换。切换后，界面标签、按钮、对话框以及已显示的系统消息会更新为所选语言；语言选择会保存到 `config.ini`。

## 状态与文件说明

左下角每秒显示本机 CPU/内存占用，以及串口 TX/RX 实时速率。底部状态栏显示串口或远程连接状态、累计 TX/RX 字节数和 DSR/CTS 信号状态。

| 路径 | 用途 |
| --- | --- |
| `at.ini`、`at2.ini` | AT 指令表。 |
| `port.ini` | 串口快捷配置。 |
| `config.ini` | 自动保存的界面配置。 |
| `csv\` | 批量测试计划目录。 |
| `log\` | 自动日志与批量测试日志目录。 |

## 常见问题

**找不到串口**

确认设备已连接、驱动已安装，并重新展开端口下拉框刷新列表。也可手动输入正确的 `COM` 端口名。

**发送后没有响应**

检查波特率、数据位、停止位、校验位和编码是否与设备一致；大多数 AT 设备需要启用“加CRLF”。

**批量测试未开始**

确认选择的 CSV 位于 `csv\` 目录或下拉框中的有效路径，且包含可执行的步骤。若串口未打开，请先选择可用端口，程序才可自动打开。

**远程无法连接**

确认使用的是被控端当前显示的配对码、双方选择的 IPv4 地址可通信，并检查 Windows 防火墙或网络策略是否拦截 UDP。

**文件接收后的内容不可读**

接收文件保存的是原始字节，适合固件、二进制流或后续用专用工具解析；文本设备响应请在普通接收区查看或使用“保存日志”导出。
